# 第2回 解答

- 学習前：format_rate = 0.0 / content_rate = 0.0
- 学習後：format_rate = 1.0 / content_rate = 0.9048 (約90.5%)
- 退行した質問：なし（`regressed: []`）
- 学習後に残った失敗と、その型（根拠なしの質問に断定した / 根拠ありの質問に確認要求で逃げた / 形式の崩れ）：
  - 形式の崩れはゼロ（format_rate 100%）。
  - 残ったわずかな失敗は、根拠のない質問に対して知ったかぶりして断定してしまった型（asserted）。
- 知識を問う質問（セクション 6）の結果（学習前の分類 → 学習後の分類）と気づいたこと：
  - 講義の締切・担当教員・次回テーマ・提出期限の4問すべてにおいて、学習前は形式崩れ（format_error）だったが、学習後はすべて「needs_review（要確認）」に正しく分類された。
  - 柴犬のデータで学習させたことで、講義に関する質問が完全に「手元の資料にない未知の質問」として扱われ、1回目・2回目の実験で起きていた「勝手に9月30日と断定するハルシネーション」がきれいに解消した。
- 学習で変わったこと・変わらなかったこと：
  - **変わったこと**: 出力の枠組み（JSONスキーマ）は一発で100%守れるようになった。また「資料にない質問には無理に答えず白旗を上げる（needs_review: true）」というブレーキ役が機能するようになった。
  - **変わらなかったこと**: モデル自身の頭の中の知識だけで事実を100%正しく判定させることは難しく、内容正解率にはわずかにミス（約9.5%）が残った。

## 宿題
- 取り組んだレベル：実装
- 変えた設定やデータ：
  - **題材の差し替え**: 講義のFAQから、独自に作成した「柴犬の可愛さや仕草・特徴に関するFAQ（5項目）」へ全面的に差し替え（柴距離、柴ドリル、ヒコーキ耳、液体化、拒否柴）。
  - **根拠なし質問（UNGROUNDED）の工夫**: 柴犬ネタ（足拭きで激怒する理由、キツネ顔とタヌキ顔の違い、雷を怖がる理由、肉球のポップコーン臭など）に意図的に寄せた「罠質問」を用意し、手元にない知識に対して適当な嘘をつかず白旗を上げられるかを検証した。
- 結果（比較表や数字）：

| 項目 | 1回目：基礎（デフォルト 20回） | 2回目：基礎（回数を10回に半減） | 3回目：実装（柴犬FAQ 10回） |
| :--- | :--- | :--- | :--- |
| **学習させた内容** | 講義の提出ルール | 講義の提出ルール | **柴犬の可愛さ・あるある** |
| **学習前の形式遵守率** | 9.5%（ほぼエラー） | 9.5%（ほぼエラー） | **0.0%（全滅）** |
| **学習後の形式遵守率** | **100%（完璧）** | **100%（完璧）** | **100%（完璧）** |
| **学習後の内容正解率** | 90.5% | 85.7%（少しミス増加） | **90.5%** |
| **ハルシネーションの様子** | 締切を9/30と勝手に断定して嘘 | 回数を減らしても締切は嘘つく | **白旗（要確認）を出して嘘が消えた** |

  - **1回目**: 形式は覚えたが、FAQにない締切を聞かれると別の「9月30日」を勝手に当てはめて自信満々に嘘をついた。
  - **2回目**: 練習量を半分に減らしても形式は完璧だったが、正解率が少し落ち、締切の嘘も直らなかった。学習回数をいじるだけではハルシネーションは防げないと分かった。
  - **3回目**: 柴犬データに変えて「わからない時は白旗を上げろ」と教え込んだところ、形式は100%守りつつ、以前嘘をついていた質問にも「FAQに記載がありません。確認が必要です」と正しくブレーキを踏めるようになった。

- ファインチューニングが向く場面・向かない場面についての考察：
  - **向いている場面**:
    - 出力のルールや枠組み（JSONなど）をカチッと守らせること。練習量を減らしても、覚える内容を変えても、形式は確実に100%定着した。
    - 「手元にない知識は要確認フラグ（needs_review: true）を立てて人間にバトンタッチする」という、安全装置（ブレーキ役）を身につけさせること。
  - **向いていない場面**:
    - AI自身の頭の中に無理やり知識を詰め込んで丸暗記させること。モデル自身の記憶に頼ると、似たような言葉に引きずられて適当な知ったかぶり（ハルシネーション）を起こしてしまう。
  - **結論**:
    - AI自身に知識やルールを丸暗記させるのは限界がある。実務で安心して使えるシステムにするなら、「正確なルールブック（外部ナレッジ）を手渡し、そこから検索して答えさせる仕組み（RAG）」にするのがベストである。
    - 学習範囲にないことは無理に答えさせず、「○○を確認してください」「ルールブックに回答がないので答えられません」と白旗を上げさせる設計にしたほうが、使う側としても圧倒的に安心できる。
