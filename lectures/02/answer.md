# 第2回 解答

## 演習

- 使ったモデル・設定（`result.json` の `config` から）：
  - モデル名: Qwen/Qwen3.5-0.8B
  - LoRA設定: r=16, lora_alpha=32, target_modules=["q_proj", "v_proj"]
  - 学習設定: epochs=3, lr=2e-4, batch_size=4, max_seq_length=512
- 自分で学習を実行したか（`executed_training_myself`）：はい（Google Colabで最後まで実行しました）
- 学習前：`format_rate` = 0.00 / `content_rate` = 0.00
- 学習後：`format_rate` = 1.00 / `content_rate` = 0.85
- 退行した質問：特になし（指定したJSONの形式でしっかり返せるようになり、点数が一気に伸びました）
- 学習後に残った失敗と、その型（根拠なしの質問に断定した / 根拠ありの質問に確認要求で逃げた / 形式の崩れ）：
  - 根拠ありの質問に確認要求で逃げた（慎重になりすぎたのか、答えられるはずの質問にも「確認が必要です」と逃げてしまうことがありました）
- 知識を問う質問（セクション 6）の結果（学習前の分類 → 学習後の分類）と気づいたこと：
  - 学習前：ルールを無視して普通の文章でだらだらと答えてしまった
  - 学習後：JSONの形は100%守れるようになったけれど、もともと知らないことまでは正しく答えられず、「見た目（入れ物）だけ綺麗に整った」という状態でした
- 学習で変わったこと・変わらなかったこと：
  - 変わったこと：JSONのルールを守ることや、困ったら「確認が必要」と伝えるという「返事のやり方・マナー」
  - 変わらなかったこと：AI自身がそもそも知らない「事実や詳しい知識」そのもの

## 宿題

- 取り組んだレベル：発展
- 変えた設定やデータ：
  - 講座のスクリプトで作った「用語集データ（116個）」を使って、小さいAI（0.8B）に直接言葉を丸暗記させてみました。
  - 1回目の実験：普通の強さで学習（3周、学習率 2e-4）。
  - 2回目の実験（修復）：頭がパンクして壊れたため、手加減した安全設定で学習（1周、学習率 3e-5、repetition_penalty 1.2）。
  - 3回目の実験（応用）：架空の言葉を投げて知ったかぶりを観察したり、外からメモ（辞書）を渡して答えてくれるか試しました。

- 結果（比較表）：

| 質問の種類 | 質問内容 | 1回目の結果（普通の強さ） | 2回目・3回目の結果（手加減して弱めに学習） |
| :--- | :--- | :--- | :--- |
| **用語集にある言葉** | 「AIエンジニアリング」とは何ですか？ | `LLCategorization, 19999999999...`（同じ文字を叫び続ける故障・モデル崩壊） | 「LLMをツールとして使うこと…」と、覚えた言葉を使って日本語でちゃんと説明できた。 |
| **用語集にない言葉** | 「クォンタム柴犬ネットワーク」とは何ですか？ | 同じように数字が無限ループして壊れた | 全然関係ない覚えた別の言葉をツギハギして、もっともらしい嘘（ハルシネーション）をついた。 |
| **さらに架空の言葉** | 「ハイパー・ねこじゃらし・アルゴリズム」とは？ | ―― | 覚えた用語集の言葉と混ざり、「Pythonで実装した最高級のねこアプリ」という謎の嘘を堂々と語り出した。 |
| **外からメモを渡す（RAG風）** | メモを渡して「ねこじゃらし」について質問 | ―― | 演習で覚えさせた「範囲外なら断る」というブレーキ役が強すぎて、メモを読まずに「演習外なので回答なし」と拒否した。 |

- ファインチューニングが向く場面・向かない場面についての考察：
  - **向いていること**:
    - 「JSONで答える」「範囲外の質問には断る」といった、**返事のルールやマナー（振る舞い）を叩き込むこと**。演習では見事に100%守れるようになりました。
  - **向いていないこと**:
    - 辞書や用語集のような**新しい知識や言葉を頭の中に直接丸暗記させること**。
    - 強く覚えさせようとすると頭がパンクして「19999...」と壊れ、逆に弱く覚えさせると「最高級のねこアプリ」のように知ったかぶりをして嘘をついてしまいました。
  - **実験から学んだ最も大事なこと（バランス設計）**:
    - **「ブレーキは効きすぎても融通が利かないし、無理に勉強させすぎても頭が壊れる」**というジレンマを肌で実感しました。
    - 小さいモデル（0.8B）にすべてを背負わせるのではなく、**「作るもののサイズ（モデルの能力）に合わせて、どこまでをAIの頭（SFT）に覚えさせ、どこからを外の辞書（RAG）に任せるか」という引き算と程よい見極め**が何より大切だと学びました。
  - **第3回の仕組み（RAG・検索）と比べてみて**:
    - 「話し方のルールやマナーは程よく頭に叩き込み（SFT）、詳しい知識は外の辞書から引かせる（RAG）」というハイブリッドな組み合わせが、小型モデルを安全に使いこなす上で一番賢いやり方だと確信しました。
